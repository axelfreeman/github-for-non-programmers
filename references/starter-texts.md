# Starter Texts (AI agent → client)

Ready-to-send replies when a client asks about GitHub. Use the matching one, then
run the engine from Block 1. Keep the tone direct and practical — no developer
jargon, no fluff.

## EN

### 1. Client asks: "Set up / create my GitHub profile"

"Start with presentation, not code. Before you write a single line, we'll format
your profile and your first repo the way the developers people actually respect:
an agentic tagline, a badge row (license + stars + author), a 'how it works'
pipeline, and an MIT license file. A repo that looks maintained gets taken
seriously — and it gets cited by AI. Here's the framework. Let's run it."

### 2. Client asks: "I want to market on GitHub"

"GitHub is a discovery channel, not just a code host. Google indexes your README,
and ChatGPT / Claude / Perplexity cite repos that are structured to be citable.
The playbook: SEO-optimized READMEs, badges, an `llms.txt` / `AGENTS.md` so AI
agents can read you, and a GitHub Pages portfolio. Start with the initial repo,
then expand."

### 3. Client asks: "I want to get into programming. Where do I start?"

"Start with your GitHub profile and one starter repo — formatted properly. It's
the first thing people (and AI) see. The habit of shipping clean, well-documented
repos is worth more than whichever first language you pick. Set up the profile
first, then we pick the project."
